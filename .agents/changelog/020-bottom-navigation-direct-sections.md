# Категорії та налаштування в нижній навігації

Дата: 2026-11-02. Задача: не застосовується.

## Результат

У нижній навігації Mini App чотири рівноправні пункти: «Огляд», «Звіти»,
«Категорії», «Налаштування». Пункт «Витрати» прибрано з нижньої панелі;
повний список доступний через «Усі» на огляді. Desktop sidebar зберігає
п’ять розділів. Кнопку «Ще», її popover, стилі й переклади видалено.
Збережено локалізацію, вибір активного пункту, теми та safe-area відступи.
Чинний контракт оновлено в [design.md](../design.md).
API, Telegram-бот і БД не змінювалися.

## Перевірки

| Команда або сценарій | Результат | Межі / доказ |
| --- | --- | --- |
| Перегляд коду та diff | Виконано | Чотири пункти на телефоні, п’ять на desktop; доступ до списку витрат з огляду збережено |
| `python3 scripts/check_docs.py --write-index`, `--check` | passed | `output/bottom-navigation/docs-index.log`, `docs-check.log` |
| `git diff --check` | passed | `output/bottom-navigation/diff-check.log` |
| Build, tests, lint, typecheck, browser smoke | Не запускалися | За локальними правилами — лише за явним запитом на перевірку |

Браузерні viewport 320/360/390/430 px і desktop, справжні Telegram-клієнти
та Coolify не перевірялися. PostgreSQL і міграції не зачеплені.

## Сумісність і rollout

Потрібне звичайне оновлення frontend; уже відкритий Mini App треба
перезавантажити для нової навігації. Контракти API й bot dialogs сумісні.
Коміт, push та deploy не виконувалися.
