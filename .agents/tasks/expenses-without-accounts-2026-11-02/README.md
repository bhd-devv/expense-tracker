# Витрати без фінансових рахунків

Стан: `done`. Дата: 2026-11-02.

## Результат і критерії приймання

Один Telegram-профіль користувача, категорії та витрати. Фінансових рахунків,
надходжень і балансів немає. Витрата/чернетка має власну валюту; валюта
профілю є типовою для нової чернетки. Збережені суми/валюти не конвертуються.
Mini App, бот, API та seed використовують однакову спрощену модель.

## Scope / non-goals

Прибрати рахунки з UI, bot actions, DTO, фільтрів, seed та EF model.
Додати міграцію для існуючої БД зі збереженням витрат і валют чернеток.
Зберегти ownership, CSRF, ідемпотентність, категорії та точну арифметику.
Нових фінансових сценаріїв, коміту, деплою та production міграції немає.

## Рішення й ризики

Міграція видаляє старий каталог рахунків та його посилання; історичні витрати
зберігають свою валюту. Потрібен backup і узгоджений release всіх сервісів;
старий frontend потребуватиме повторного відкриття. Скасувати видалення
каталогу через image rollback неможливо. Локальні build/tests/browser та
контейнерні перевірки запускаються лише за окремим запитом користувача.

## Виконання й перевірки

| Команда або сценарій | Результат | Межі |
| --- | --- | --- |
| Аналіз коду/diff і пошук старих залежностей | Виконано | Рахунки лишилися лише в історичних міграціях, migration regression і compatibility-кнопках старого бота |
| `npm run generate` | Виконано | TypeScript із оновленого checked-in OpenAPI; live export API не запускався |
| `uv run --frozen --offline datamodel-codegen ...` | Виконано | Pydantic із того самого OpenAPI; без запуску API |
| Prettier `--write`, Ruff `format` змінених файлів | Виконано | Форматування коду; не runtime перевірка |
| PostgreSQL regressions: міграція, валюта, ownership, seed | Оновлено/додано, не запущено | Реальна БД не використовувалася |
| Fake Telegram regressions: валюта, старі дії, seed | Оновлено/додано, не запущено | Реальні повідомлення не надсилалися |
| Build/tests/lint/typecheck/browser/Compose/Coolify | Не запускалися | Вимога перевірок лише за окремим запитом |
| Документація та `git diff --check` | Див. changelog | Докази в `output/expenses-without-accounts/` |
