# Редагування назви категорії безпосередньо в рядку

Дата: 2026-11-02. Задача: не застосовується — локальна UI-правка.

## Результат

Кнопка редагування категорії в Mini App тепер замінює назву полем у тому
самому рядку. Поруч — збереження й скасування; Enter зберігає, Escape
скасовує. Поле отримує фокус і виділення; після завершення фокус повертається
на кнопку редагування цієї категорії. Поле має локалізовану accessible name,
required/maxLength; помилка API зберігає введення для виправлення.

Нижня форма призначена лише для створення. Її назва/іконка незалежні від
редагування наявної категорії. Зміна іконки під час редагування оновлює
версію категорії, зберігаючи введену назву й стан створення. Збереження
незміненої локалізованої назви передає оригінальну назву backend, щоб
не втратити системний code. Використовується чинний PUT із version checks.

Backend, API, БД і сценарій перейменування бота не змінювалися; можливість
бота вже існує. Попередні локальні зміни іконок/видалення збережені.

Реальні Telegram-клієнти, PostgreSQL і Coolify не перевірялися. Нових тестів
для локальної оборотної UI-правки не додано. Міграції й реальні дані не змінювалися.

## Сумісність і rollout

Потрібне оновлення frontend image й перевідкриття Mini App; нових залежностей,
API-полів або міграцій ця правка не додає. Build/browser перевірки очікують
окремого запиту. Коміт, push і deployment не виконувалися.
