# Компактний Mini App і єдина валюта

Стан: `completed`. Дата: 2026-11-02.

## Результат і критерії приймання

Компактні відступи й форми в усіх розділах, заголовок редактора в один рядок,
видимі дії збереження. Зони натискання не менші за 44 px, поля — 16 px.
Валюта вибирається лише в налаштуваннях і позначає всі витрати, звіти та
ліміти та накопичення. Зміна валюти не змінює введені суми, включно з дробовими значеннями.

## Scope / non-goals

Спільні стилі, редактори Mini App, спільні backend-сценарії та бот.
Без нових залежностей, міграції, коміту або деплою. Наявна паралельна
робота над заощадженнями збережена; за окремим уточненням користувача
спільне позначення валюти застосоване також до її залишків та історії.

## Рішення й ризики

Валюта профілю — єдине джерело позначення; legacy поля Currency у записах
та запитах зберігаються для сумісності, але не керують відображенням або
групуванням. Суми зберігаються без конвертації. Старі відкриті клієнти
потребують оновлення, старі кнопки вибору валюти витрати відхиляються.
