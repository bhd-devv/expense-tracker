# Ручне та AI-введення витрат

Стан: `completed`. Дата: 2026-11-02.

## Результат і критерії приймання

Налаштування «Ручне / AI» спільне для Mini App і бота. Ручне додавання
дозволяє заповнити суму, валюту, категорію, опис і дату без AI. AI розбирає
текст або голос у редаговану чернетку. Сьогодні за часовим поясом профілю —
початкова дата; явна дата у формі або описі має пріоритет. Відносна дата
рахується від дня приймання, повтор не зсуває її. Збереження явне й ідемпотентне.

## Scope / non-goals

Backend, additive migration налаштування профілю, OpenAPI/generated DTO,
Mini App, aiogram, локалізація uk/en, регресійні сценарії та документація.
Без коміту, push, deployment, production migration чи реальних AI/Telegram запитів.

## Рішення й ризики

Режим введення відокремлено від згоди на зовнішню AI-обробку. Наявний AI
сценарій початковий для сумісності; ручний режим не потребує згоди або ключа.
Обидва режими використовують ті самі чернетки й серверне підтвердження.
Явна дата AI є недовіреною пропозицією й перевіряється backend.
Невизначена дата потребує уточнення, а не мовчазного збереження сьогодні.
