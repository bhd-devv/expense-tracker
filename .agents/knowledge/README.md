# Чинні контракти та рішення

У `knowledge/` зберігай прийняті рішення та детальні контракти, які мають
залишатися актуальними між задачами. Для нового рішення використовуй
[decision.md](../templates/decision.md). Не дублюй один контракт у task,
changelog і кількох правилах: вибери одне джерело правди й посилайся на нього.

Історичні дослідження, changelog та archive не перетворюються на чинні
рішення автоматично. Якщо код змінив контракт, спочатку онови цей документ
або явно зафіксуй supersession у новому ADR.
