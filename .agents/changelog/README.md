# Changelog

Тут зберігається детальна історія завершених змістовних задач. Один запит або
одна пов'язана група дрібних змін отримує один запис:
`.agents/changelog/<номер>-<назва>.md`.

## Правила запису

1. Візьми номер строго вище найбільшого наявного числового префікса; не
   перенумеровуй історію й не перевикористовуй номер.
2. Використовуй kebab-case назву та шаблон
   [change.md](../templates/change.md).
3. Опиши результат, причину, вплив на API, Mini App, Telegram-бота та БД,
   фактично виконані перевірки, пропущені перевірки, обмеження, міграції,
   сумісність, release і rollback.
4. Записуй лише те, що реально виконано. План або пропозиція належать до
   `tasks/` чи `research/`, а не до changelog.
5. Не додавай у текст секрети, повні Telegram payloads, cookie, токени,
   production credentials або приватні фінансові дані.
6. Після додавання запису онови індекс командою:
   `python3 scripts/check_docs.py --write-index`.

Історія не є поточним контрактом і не дає дозволу на коміт, міграцію, деплой
чи продовження старої задачі. Актуальний контракт живе в `.agents/*.md` або
`.agents/knowledge/`; changelog посилається на нього.
