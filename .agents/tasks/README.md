# Робочі записи задач

Велику, багатокрокову або незавершену роботу веди в одному файлі:
`.agents/tasks/<назва>-<YYYY-MM-DD>/README.md`, створеному з
[task.md](../templates/task.md).

Файл має містити критерії приймання, scope і non-goals, план, рішення й
ризики, фактичні перевірки, останній завершений крок і точну наступну дію.
Додаткові файли створюй лише для справді великої специфікації або review.
Для маленької правки не створюй окремі plan/report/handoff документи.

Стан задачі: `planned`, `in_progress`, `verification`, `done`,
`blocked`, `needs_revalidation`. `blocked` вимагає конкретної зовнішньої
причини та умови розблокування. Завершену задачу підсумуй у changelog і
прибери з активної частини `STATUS.md`.

Task-файл описує роботу, а не замінює чинний контракт. Посилайся на
`.agents/product.md`, `architecture.md`, `security.md`, `telegram.md` або
`knowledge/`, замість дублювати їхні правила.
