# Демо-витрати за жовтень через /seed

Стан: `completed`. Дата: 2026-11-01.

## Результат і критерії приймання

- `/seed` у приватному чаті додає 70 витрат за 1–31 жовтня 2026 року
  лише поточному Telegram actor; усе видно в Mini App і боті.
- Набір покриває всі 31 день, 7 категорій, 4 деморахунки та UAH/USD/EUR.
- Повторний або конкурентний виклик не дублює дані й не відновлює
  відредаговані/видалені демовитрати. Уся операція атомарна.
- Спільні серверні перевірки суми, рахунку й категорії; без OpenRouter.
- Команда має кнопковий відповідник у налаштуваннях бота, uk/en відповіді.
- DTO генеруються з backend OpenAPI; migration додає receipt демонабору.
  Дані не засіваються при startup/deploy.

## Scope / non-goals

Backend feature, приватний actor endpoint, receipt у PostgreSQL, aiogram
handler і кнопка, DTO генерація, релевантні тести та документація.
Немає cleanup, довільного Telegram ID у body, змін особистих записів
або нової сторінки Mini App: це явна технічна команда для тестування.

## Рішення й ризики

Рік фіксований: 2026, оскільки користувач попросив жовтень 2026-11-01.
Receipt зберігається окремо від витрат, щоб видалення витрати не дозволяло
повторне наповнення. Transaction + user advisory lock серіалізують запити.
Нові рахунки позначено «Демо»/«Demo»; активні системні категорії
використовуються повторно, архівні не змінюються. Ліміт каталогу 50
перевіряється до запису, особисті дані й профіль не змінюються.

## Виконання й перевірки

Перевага користувача зберігається: application tests/build/lint/typecheck
як перевірки не запускаються без окремого запиту. Компіляція, необхідна
для генерації EF migration та OpenAPI, є частиною авторингу артефактів;
її не представлено як повну перевірку застосунку. Міграція до production
або локальної БД не застосовувалася.

Згенеровано `AddDemoSeeds` через EF tool 10.0.12 (компіляція успішна).
OpenAPI отримано з локального Development API на 5099 із синтетичною
конфігурацією; `scripts/generate_contracts.py` оновив обидва consumers.
Server URL артефакту залишено стандартним 5085. API після генерації зупинено.
Додано PostgreSQL-тести одноразовості/конкуренції, isolation, каталогів,
звітів/каналів і pytest для маршрутизації `/seed` після ingress та uk/en
повідомлень, limit/timeout без прихованого retry; їх не запускали.
Результати документаційних перевірок — у [changelog](../../changelog/014-october-demo-seed.md).

## Продовження / результат

Реалізацію завершено локально; правила описані в product/telegram і ADR-011.
Після деплою з міграцією користувач може викликати `/seed` і вибрати
жовтневий період у Mini App/боті. Не виконано коміт, push, деплой або
живе наповнення. Паралельні зміни logging/deployment з іншої задачі
збережено; вони не належать до цього демонаповнення.
